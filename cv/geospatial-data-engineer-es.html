Jay Antonio Oliver

Ingeniero de datos geoespaciales

Perfil

Científico de datos geoespaciales y desarrollador con más de seis años creando procesos reproducibles y herramientas analíticas. Integra APIs, bases de datos y archivos heredados con Python/SQL, priorizando calidad, identificadores y coordenadas. Automatiza análisis espaciales y comunica resultados. Creador y único desarrollador de PredioAI; bilingüe inglés/español, con experiencia en investigación ambiental y energética.

Competencias principales

Ingeniería de datos: Python, SQL, R, pandas, NumPy, ETL, APIs REST, PostgreSQL, archivos de ancho fijo, Linux, Bash y Git.

Procesamiento geoespacial: GeoPandas, GDAL, Rasterio, ArcGIS Pro, ArcGIS Enterprise, Experience Builder, Shapely, pyproj; procesamiento ráster/vectorial, uniones espaciales, transformaciones de coordenadas y series temporales satelitales.

Software y validación: FastAPI, React, Leaflet, PyMuPDF, ezdxf, GitHub Actions, verificaciones automatizadas, estandarización de datos y documentación técnica.

Experiencia relevante

Leidos — Científico de Datos Geoespaciales

Morgantown, WV · Investigación para NETL | feb. 2024 – may. 2026

  • Convertí más de 400 rásteres geológicos a capas vectoriales con control de calidad; preparé mapas web por cuenca para el atlas de NETL.

Baylor University — Responsable de Laboratorio / Científico de Datos Geoespaciales
