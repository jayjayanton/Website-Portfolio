Introduction

Yuyay Analytics is a consulting website presenting environmental programme evaluation, sustainability research, predictive modeling and geospatial intelligence. The project brings together Clemencia Vela's international environmental evaluation experience and my technical work in environmental data science, including research in the United States.

Methods & development

  • Frontend: Built static pages using semantic HTML, responsive CSS and JavaScript, with navigation, project filtering and interactive cards.
  • Content architecture: Organized Services, Projects, Countries, Publications, Team, Analytics and Contact into distinct sections with consistent navigation and visual hierarchy.
  • Geographic storytelling: Integrated country imagery and project descriptions for Latin America, the Caribbean and the United States.
  • Evidence and attribution: Connected project descriptions to public technical reports, NASA DEVELOP research, evaluation documents and my 2025 Scientific Data publication.
  • Visual design: Implemented scenic photographic heroes, a reusable color palette, responsive mobile layouts and icon-based analytics capabilities.
  • Delivery: Version-controlled the website in GitHub and published it through GitHub Pages.

Technical features

The project includes interactive project cards, country and thematic filters, links to downloadable CVs and reports, a research bibliography, and a contact form that opens the visitor's email application with a prepared inquiry. The contact form is not a backend email-delivery system.

What this project demonstrates

This project illustrates my ability to translate a multidisciplinary consulting brief into a functioning public-facing website, organize technical research into accessible case studies, and iterate on responsive UI, assets, and JavaScript behavior. It also demonstrates the integration of environmental domain knowledge with practical frontend development.

Technology: HTML · CSS · JavaScript · Git · GitHub Pages · Responsive UI
