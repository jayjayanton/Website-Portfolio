Ra'az Borg — Web Development

A multi-page combat-sports website built around an underground grappling identity, with responsive navigation, bilingual content and interactive presentation.

Project GitHub Repo Open GitHub Pages website

This is a fork of daveeedlr/raaz-borg. The case study describes features visible in the current fork; the scope of my modifications will be documented after my updated local version is pushed. The GitHub Pages link depends on the fork's publishing configuration.

01Project summarySite and purpose

Ra'az Borg presents an underground grappling platform through a fictional, cyberpunk-inspired visual identity. The current repository contains five pages: Universe, Fighters, Clashes GP, Labs & Media, and Shop. The site is organized as a static web application with shared CSS, JavaScript, and image assets.

02Frontend architectureHTML, CSS and JavaScript

The fork uses HTML, a shared css/style.css stylesheet and js/main.js for interface behavior. The code includes an English/Spanish language toggle with browser storage, mobile navigation, scroll-reveal effects, animated tickers, and additional page interactions. The repository requires no frontend build step.

The current GitHub fork does not include a Node.js/PostgreSQL backend. Any backend prototype should be documented separately until its code has been uploaded and verified.
