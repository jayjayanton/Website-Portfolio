# Land-cover figures for my research portfolio

I use these figures to show how the land-cover harmonization workflow connects the original source classifications with the MSD base map and the model-specific GCAM, CLM, and LUH2 representations.

- `figure-01-sankey-diagram.png` — Figure 1: the Sankey diagram showing how source land-cover categories pass through classification and climate/ecoregion processing steps.
- `figure-02-msd-classes.png` — Figure 2: spatial distribution of MSD classes across the conterminous United States.
- `figure-03-gcam-msd.png` — Figure 3: GCAM–MSD comparison, including a national map and a closer regional example.
- `figure-04-luh2-msd.png` — Figure 4: LUH2–MSD land-cover comparison.
- `figure-05-clm-msd.png` — Figure 5: CLM–MSD plant functional type comparison.

The [land-use case study](../projects/land-use-dynamics.html) references these filenames. The image assets need to be uploaded before they will display on GitHub Pages.

Paper: [Scientific Data (2025)](https://www.nature.com/articles/s41597-025-04713-6). I retain the original figure attribution and applicable publication reuse terms.
